# Historical implementation evidence — superseded

This file preserves the existence of the pre-v2 screen audit without granting it design authority.

Prior to KONFRM Design System v2.0.0, parts of the Owner App were treated as a forensic source for local colours, component shapes and dark-header treatments. That model is superseded.

- The Owner App is **not** an authoritative visual source.
- Customer and Admin are **not** authoritative visual sources.
- Existing implementation is evidence for the migration backlog only.
- Dark/glass header and navy-surface observations are legacy drift, not approved design language.

For current rules, use [`README.md`](./README.md), [`GOVERNANCE.md`](./GOVERNANCE.md), [`TOKENS/`](./TOKENS) and [`LEGACY_DRIFT.md`](./LEGACY_DRIFT.md).
