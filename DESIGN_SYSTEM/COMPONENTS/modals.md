# Modal and ConfirmationDialog

Use a Modal only when inline or progressive disclosure is unsuitable. It has `surface.elevated`, `radius.modal`, `modalPadding`, controlled overlay elevation, focus management, escape/close behaviour and a labelled title.

`ConfirmationDialog` is reserved for meaningful, consequential confirmation. It states the consequence, uses a primary safe action and a separately clear destructive action when relevant; it never hides the consequence behind colour alone.
