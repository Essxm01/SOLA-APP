# KONFRM Product Experience System

**System version:** `2.1.1`
**Authority:** `DESIGN_SYSTEM/` governs both visual foundations and role-specific product experience.

```
DESIGN_SYSTEM/
├── Visual foundation: TOKENS, COMPONENTS, GUIDELINES
└── EXPERIENCE/
    ├── Shared governance and state rules
    ├── Customer, Owner and Admin experience contracts
    ├── Entry, navigation, information and action authority
    └── Current-state audit, inventory and Founder decisions
```

Consistency does not mean an identical experience. All applications share KONFRM foundations, status language, accessibility and interaction semantics. Their information hierarchy, density, navigation and action prominence follow the user’s job.

This directory is governance and migration planning only. It does not change routes, backend permissions, booking/payment logic, or live UI.

Read [GOVERNANCE.md](./GOVERNANCE.md) before proposing a new pattern. The nontechnical review source is [../FOUNDER_EXPERIENCE_REVIEW_AR.md](../FOUNDER_EXPERIENCE_REVIEW_AR.md).
