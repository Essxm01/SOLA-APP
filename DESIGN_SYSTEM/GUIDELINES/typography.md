# Typography authority

Cairo is the official and only primary KONFRM UI family. Use the semantic roles in [`TOKENS/typography.json`](../TOKENS/typography.json): display, pageTitle, sectionTitle, cardTitle, body, bodyStrong, label, caption, button, numeric and metadata.

Arabic readability leads. Default operational body text is 14px; required mobile content is never 9px/10px. Numeric values may use tabular figures but keep the surrounding UI in Cairo. Applications may not independently introduce Amiri, a display family or a local font hierarchy.
