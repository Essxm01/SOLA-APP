# 🔤 SOLA Guidelines — Typography Usage & Font Pairing

---

## 1. Primary Font: Cairo
- Load via Google Fonts: `https://fonts.googleapis.com/css2?family=Cairo:wght@400;500;600;700;800;900&display=swap`
- Set in CSS: `font-family: 'Cairo', system-ui, sans-serif;`

---

## 2. Monospace Font: Numbers & Identifiers
- Used for: EGP Amounts, Dispute Codes (`DSP-2026-001`), Booking IDs (`BK-2026-8812`), Phone numbers (`+201012345678`), and IBANs.
- Class: `font-mono font-bold`

---

## 3. Font Weight Guidelines
- `font-black` (900): Main page titles, primary numerical figures.
- `font-extrabold` (800): Section headings, status badges.
- `font-bold` (700): Card headers, button text, table header columns.
- `font-semibold` (600): Input labels, table row body text.
- `font-medium` (500): Helper text, secondary metadata.
