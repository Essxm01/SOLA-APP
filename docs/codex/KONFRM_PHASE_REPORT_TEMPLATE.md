# Phase closure report template

```md
# [P<macro>.<sequence>] — Closure report

## Result and outcome
## Authority / current-reality evidence
## Changed areas and affected roles
## Data, API, storage, and infrastructure impact
## Acceptance criteria: individual PASS / FAIL results
## Tests and checks executed
## Functional, failure-state, and regression proof
## Interactive UI evidence and screenshots (if applicable)
## Cross-app verification (if applicable)
## Security/privacy review
## Exact live revision and live verification (if applicable)
## Defects discovered and fixed during self-review
## Deferred defects and valid deferral reason
## No known unresolved in-scope defect at closure: Yes / No
## Documentation, matrix, and backlog updates
## Git state and recommendation
```

Never report Complete when any acceptance criterion fails or an in-scope defect remains unresolved.
